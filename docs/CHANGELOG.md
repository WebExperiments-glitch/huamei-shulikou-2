# 更新日志

## 0.1.0-preview — 2026-08-10

### ✨ 初始版本

全栈术力口周榜项目首次发布。

### 核心功能

- **周榜/传说曲榜/年榜**：官方公式（Δ播放×t + Δ收藏×15 + Δ点赞×3 + Δ投币×30），已用 112 期官方 API 全量对拍验证
- **实时热度 HotBoard**：综合榜 + 涨速榜（快照差分），殿堂/传说/神话分级
- **歌曲库**：12381 首收录池搜索、筛选、排序
- **P主/歌姬榜**：统计排名与代表作
- **歌曲对比**：跨期多曲对比
- **数据分析**：趋势可视化
- **公式与试算**：交互式得分计算器
- **年度回顾**：年榜 KPI + 分数分布
- **传说曲晋升时间线**：里程碑追踪

### AI 智能体

- 50 个工具：数据查询 / 联网搜索 / 生成式图表 / 关系图谱 / 跨平台对比 / 收藏管理
- ReAct 循环（云端 DeepSeek-V4-Flash）
- 权限分级：只读 / 客户端操作 / 危险操作（均需人类确认）
- 多会话保存（localStorage + 后端 SQLite 双写）
- 流式缓存命中

### 网易云音乐集成

- 搜索（单曲/歌手/专辑/歌单）
- 详情页（歌词/评论/热度/播放）
- 内置播放器（队列控制）
- 自研 WeAPI 加密（weencrypt.py，MIT 协议）

### 技术设施

- FastAPI 后端（CORS 白名单 / 安全头 / 限流 / 缓存 / 输入校验）
- React 19 + Vite 8 + ECharts 前端
- 浅色/深色主题一键切换
- 移动端响应式（抽屉导航 / 汉堡菜单）
- 命令行面板（⌘K 搜索跳转）
- 收藏系统（localStorage 持久化）
- `.gitignore` / `LICENSE`（CC BY-NC 4.0）/ 文档完备

### 同步流水线

- `scripts/sync_official.py`：全量同步官方数据
- `scripts/build_daily.py` / `build_monthly.py`：自建榜构建
